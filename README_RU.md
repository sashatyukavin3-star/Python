# Zomdroid — Android 10 compatibility build kit

Это не готовый APK. Набор подготавливает отдельную ветку исходников и собирает APK в GitHub Actions на облачном Linux-сборщике. На самом телефоне NDK/Android SDK не компилируются.

## Что меняется

- `minSdk`: 30 → 29 (Android 10 / API 29).
- `targetSdk`: 35 → 29 для поведения разрешений и хранилища Android 10.
- API 30 `WindowInsets` заменены на AndroidX `WindowInsetsCompat`/`WindowCompat`.
- `Math.clamp` заменён выражениями на `Math.min/Math.max`, доступными старым Android runtime.
- Проверка `POST_NOTIFICATIONS` выполняется только на Android 13+.
- `compileSdk` остаётся 35; ABI остаётся `arm64-v8a`.

Патчер останавливается, если не находит ожидаемые фрагменты исходников, чтобы не сделать частичную или случайную сборку.

## Запуск на Android через Termux

1. Скачай и распакуй ZIP набора.
2. Открой Termux и перейди в распакованную папку набора.
3. Запусти:

```bash
bash termux_prepare_build.sh
```

4. Войди в GitHub через код, который покажет `gh auth login`.
5. Скрипт создаст отдельный форк `zomdroid-android10`, отправит туда ветку `android10-compat` и откроет адрес страницы Actions.
6. На странице Actions нажми кнопку включения workflows для форка, вернись в Termux и нажми Enter.
7. После успешной сборки APK будет скачан в `~/storage/downloads/zomdroid-android10.apk` (если доступ к общему хранилищу Termux уже настроен), иначе в домашнюю папку Termux.

## Важные ограничения

- Сборка будет **debug-signed** и получит отдельный package ID `com.zomdroid.android10`. Это отдельная тестовая копия; она не заменяет официальную сборку и не является официальной подписью автора Zomdroid.
- Патч исправляет совместимость Android framework/API и ограничение `minSdk`, но не добавляет поддержку GPU, которой нет в проекте.
- Устройство должно быть ARM64; эта сборка остаётся только `arm64-v8a`.
- Установка APK не гарантирует запуск Project Zomboid. В README исходного проекта указаны Android 11 и минимум 3 ГБ свободной RAM. Redmi 9 с Mali-G52 не является подтверждённой конфигурацией для Zomdroid; возможны ошибки рендерера и нехватка памяти.
- Перед запуском игры проверь свободную память и место. Сам лаунчер и сама Windows/Linux-игра — разные уровни совместимости.
- Скрипт не удаляет приложения, сохранения или файлы на телефоне. Он создаёт отдельную папку `~/zomdroid-android10-build` и отдельный GitHub fork.
