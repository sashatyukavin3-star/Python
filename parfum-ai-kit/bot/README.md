# Бот «подбери аромат» — запуск в Termux за 15 минут

Один файл `quiz_bot.py`, только стандартная библиотека Python: ни pip, ни сервера, ни подписок. Держится на телефоне в Termux, работает, пока телефон в сети.

**Что делает бот:**
- приветствие с кнопками «Подобрать аромат / Цены / Доставка / Написать напрямую»;
- квиз из 5 вопросов на кнопках (человеку не надо ничего печатать);
- подбирает аромат по ответам, показывает описание и цену, предлагает пробник;
- каждую заявку пишет в `leads.jsonl` и присылает владельцу уведомление в Telegram.

Зачем это бизнесу: человек, который прошёл квиз, — это уже диалог, а не просмотр. Бот работает круглосуточно и не даёт «забыть ответить».

---

## Шаг 1. Токен бота

1. В Telegram откройте **@BotFather** → `/newbot`.
2. Имя: например `Parfum Podbor`, username: `parfum_podbor_bot` (должен заканчиваться на `bot`).
3. Скопируйте токен вида `123456789:AAH...` — это пароль от бота, никому не показывайте.

## Шаг 2. Свой chat_id (чтобы получать заявки)

Напишите **@userinfobot** — он пришлёт ваш `id` (число). Оно нужно для `OWNER_CHAT_ID`.

## Шаг 3. Установка в Termux

```bash
pkg update && pkg upgrade -y
pkg install python -y
python --version    # должно быть 3.10+
```

## Шаг 4. Файл на телефоне

Вариант А — из этого репозитория:

```bash
pkg install git -y
git clone <адрес репозитория>
cd <репозиторий>/parfum-ai-kit/bot
```

Вариант Б — вручную: скачайте `quiz_bot.py` в `Download`, затем

```bash
mkdir -p ~/bot && mv ~/storage/downloads/quiz_bot.py ~/bot/ && cd ~/bot
```

(если `~/storage` не настроен: `termux-setup-storage`)

## Шаг 5. Настройки и первый запуск

Откройте `quiz_bot.py` и поправьте блок «НАСТРОЙКИ БРЕНДА»: `BRAND`, тексты `PRICE_TEXT` / `DELIVERY_TEXT`, список `SCENTS` (названия, ноты, цены, теги) и `QUESTIONS`.

Теги — это язык, на котором бот сопоставляет ответы и ароматы. Простое правило: у аромата должны быть те же теги, что у «правильных» для него ответов (`fresh`, `green`, `bitter`, `warm`, `woody`, `sweet`, `powdery`, `musky`, `quiet`, `medium`, `loud`, `self`, `gift`).

Затем:

```bash
export TELEGRAM_TOKEN='123456789:AAH...'
export OWNER_CHAT_ID='123456789'
export OWNER_USERNAME='moy_kanal'          # без @ — кнопка «Написать напрямую»
export LEADS_FILE="$HOME/leads.jsonl"
python quiz_bot.py
```

В консоли появится «Бот … запущен». Откройте бота в Telegram, нажмите `/start` и пройдите квиз как клиент — убедитесь, что заявка пришла вам в личку.

Остановить: `Ctrl+C`.

## Шаг 6. Чтобы работал постоянно

Termux убивает процессы, когда экран гаснет, поэтому:

```bash
termux-wake-lock          # не давать системе усыплять Termux
pkg install tmux -y
tmux new -s bot
# внутри tmux:
export TELEGRAM_TOKEN='...'; export OWNER_CHAT_ID='...'; export OWNER_USERNAME='...'
python quiz_bot.py
# выйти из tmux, не убивая бота: Ctrl+B, затем D
```

Вернуться: `tmux attach -t bot`. И в настройках Android: «Батарея → Termux → без ограничений».

Если телефон перезагрузился — процесс не поднимется сам: запустите `tmux attach -t bot` и `python quiz_bot.py` снова (или добавьте `~/.bashrc`-автозапуск по желанию).

## Шаг 7. Проверка логики без сети

```bash
python -m unittest discover -s . -p "test_*.py" -v
```

13 тестов проверяют весь путь: приветствие → 5 ответов → рекомендация → запись заявки → уведомление владельцу, а также «устаревшие кнопки» и мусорные данные (бот не падает).

## Шаг 8. Что делать с заявками

```bash
# сколько заявок
wc -l ~/leads.jsonl
# последние три
tail -3 ~/leads.jsonl
# разбор: какие ароматы чаще рекомендуются
python - <<'EOF'
import json, collections, os
p = os.path.expanduser("~/leads.jsonl")
rows = [json.loads(l) for l in open(p, encoding="utf-8")]
print(collections.Counter(r["recommended"] for r in rows).most_common())
print("заявок:", len(rows), "| с username:", sum(1 for r in rows if r["username"]))
EOF
```

Пишите каждому, кто прошёл квиз, в течение дня: «Вижу, вам подошёл [аромат] — расскажите, что обычно носите?». Это и есть продажа.

## Чего бот не делает (и почему это важно)

- **Не рассылает незнакомым.** Сообщения уходят только тем, кто сам нажал `/start`. Массовые рассылки по спарсенным базам — это бан аккаунта и нарушение правил Telegram.
- **Не накручивает подписчиков.** Бот превращает интерес в диалог, но не создаёт охват: людей всё равно надо приводить (см. `../rost-bez-byudzheta.md`).
- **Не заменяет ответы человека.** Он снимает 80% повторяющихся вопросов и собирает лиды, а сложные разговоры остаются за ней.
- **Не хранит данные в облаке.** Заявки лежат файлом на телефоне. Это личные данные клиентов: не выкладывайте `leads.jsonl` в публичный репозиторий (он уже в `.gitignore`) и не пересылайте третьим лицам.
- **Не работает без интернета и включённого телефона.** Если это станет проблемой — бота можно так же бесплатно перенести на любой сервер, код не изменится.
