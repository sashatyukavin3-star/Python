# Бот «подбери аромат»: демо, Telegram, Termux

Один и тот же код в трёх ролях: **веб-демо** (потрогать без токена), **Telegram-бот** (реальная работа) и **Termux** (бесплатный хостинг в кармане). Зависимостей нет — только стандартная библиотека Python 3.10+.

```
bot/
├── config.json        всё, что нужно менять: бренд, цены, ароматы, вопросы
├── engine.py          логика: теги, подсчёт совпадений, сессия квиза
├── quiz_bot.py        Telegram-адаптер (Bot API через urllib)
├── demo_server.py     веб-демо: тот же движок, чат в браузере
├── setup_bot.py       полная настройка профиля: имя, описания, команды, меню, аватар
├── avatar.png         готовый аватар 640×640 (заменяемый)
├── selfcheck.py       проверка токена, конфига, владельца, записи заявок
├── run_bot.sh         запуск одной командой (сам включает wakelock в Termux)
├── .env.example       шаблон настроек; .env не коммитится
├── test_engine.py     18 тестов движка и конфига
├── test_quiz_bot.py   22 теста адаптера и демо
├── test_selfcheck.py  14 тестов диагностики
└── test_setup_bot.py  16 тестов настройки профиля
```

## 1. Демо за 10 секунд (без Telegram)

```bash
cd bot
python3 demo_server.py            # http://localhost:8000
```

Открывается чат в стиле Telegram: приветствие, кнопки, квиз из 5 вопросов, рекомендация с ценой, «Цены», «Доставка», «Начать сначала». Пройденные квизы падают в `demo_leads.jsonl`.

Порт меняется: `PORT=9000 python3 demo_server.py`.

Зачем демо нужно: показать бота клиенту до регистрации у @BotFather, прогнать все ветки, проверить тексты и подобранные ароматы, и увидеть, какие ответы ведут к какому флакону.

## 2. Настройка под бизнес — только `config.json`

| Поле | Что это |
|---|---|
| `brand` | название, попадает в приветствие |
| `owner_username` | ваш Telegram без `@` — кнопка «Написать напрямую» |
| `welcome`, `price_text`, `delivery_text` | тексты; переносы строк — `\n` |
| `scents[]` | `name`, `family`, `desc`, `price`, `tags` |
| `questions[]` | `text` и `options[]` с `label` и `tags` |
| `profile` | имя бота, краткое описание (до 120), описание (до 512), список команд — применяется через `setup_bot.py` |

**Как работают теги.** Каждый ответ добавляет теги, у каждого аромата свой набор; бот выбирает аромат с максимальным числом совпадений. Рабочий словарь: `fresh`, `green`, `bitter`, `warm`, `woody`, `sweet`, `powdery`, `musky`, `quiet`, `medium`, `loud`, `self`, `gift`.

Правило: у аромата должны стоять теги тех ответов, которые для него «правильные». Ошибка в тегах — единственная частая причина странных рекомендаций, поэтому после правки прогоните тесты (шаг 5) или просто пройдите квиз в демо.

Конфиг проверяется при старте: незакрытая кавычка, пустое поле или `tags` строкой вместо списка дают понятное сообщение с номером элемента, а не трейсбек.

## 3. Полная настройка профиля (одна команда)

```bash
export TELEGRAM_TOKEN='123456789:AA...'
python3 setup_bot.py --photo avatar.png
```

Что делает: ставит имя бота, короткое описание (то, что человек видит **до** `/start`), описание в профиле, набор команд в меню, кнопку меню «команды» и аватар. Лимиты Telegram (64 / 120 / 512 / 32) проверяются до запуска — скрипт не отправит то, что Telegram отвергнет.

```bash
python3 setup_bot.py --dry-run          # показать план без изменений
python3 setup_bot.py --verify-only      # что уже стоит в Telegram
```

Пример вывода `--dry-run`:

```
1. Имя бота: PARFUM · подбор аромата (23/64)
2. Краткое описание (до /start): Подберу аромат за 5 вопросов. Малые партии, пробники, без навязывания. (70/120)
3. Описание в профиле: 231 знаков из 512
4. Команды в меню: /start, /quiz, /price, /delivery, /help
5. Кнопка меню: список команд
6. Аватар: avatar.png
```

Перед изменениями скрипт делает `getMe`: если Telegram недоступен, он скажет это одной строкой и ничего не тронет (код выхода 2), а не будет молча показывать пять ошибок.

Скрипт идемпотентен: повторный запуск просто перезапишет те же значения. Падение одного шага не мешает остальным — в конце видно, что именно не применилось. Пользователям ничего не отправляется. Аватар `avatar.png` — сгенерированный, его можно заменить своим файлом 512×512.

## 4. Telegram: запуск

```bash
# 1) токен: @BotFather → /newbot
export TELEGRAM_TOKEN='123456789:AAH...'
# 2) свой id: напишите @userinfobot
export OWNER_CHAT_ID='123456789'
# 3) заявки и конфиг
export LEADS_FILE="$HOME/leads.jsonl"
export CONFIG_FILE="$HOME/config.json"   # необязательно, по умолчанию рядом со скриптом
python3 quiz_bot.py
```

В консоли — «Бот … запущен: 5 вопросов, 5 ароматов». Дальше `/start` в боте: пройдите квиз как клиент и проверьте, что заявка пришла вам в личку.

Команды: `/start`, `/quiz`, `/price`, `/delivery`. Кнопки — инлайн, человеку не нужно ничего печатать.

## 5. Termux: чтобы бот жил на телефоне

```bash
pkg update && pkg install python tmux -y
termux-wake-lock
tmux new -s bot
export TELEGRAM_TOKEN='...'; export OWNER_CHAT_ID='...'; export OWNER_USERNAME='moy_kanal'
python3 quiz_bot.py
# выйти, не убивая бота: Ctrl+B, затем D
# вернуться: tmux attach -t bot
```

В настройках Android: «Батарея → Termux → без ограничений». Токен и заявки — только локально, в облако ничего не уходит. После перезагрузки телефона процесс нужно поднять заново.

## 6. Тесты

```bash
python3 -m unittest discover -s . -p "test_*.py" -v
```

70 тестов: конфиг (битый JSON, отсутствующие поля, теги строкой), подсчёт аромата, сессия (устаревшие кнопки, ответ вне диапазона, ответ после завершения), полный путь в Telegram-адаптере, уведомление владельцу, два клиента параллельно, веб-демо и отрисовка страницы, диагностика selfcheck (формат токена, мёртвые теги, недоступный владелец, коды выхода), план и применение настройки профиля, multipart-загрузка аватара, лимиты Telegram.

## 7. Что делать с заявками

```bash
wc -l ~/leads.jsonl                                   # сколько заявок
tail -3 ~/leads.jsonl                                 # последние
python3 - <<'EOF'
import json, collections, os
rows = [json.loads(l) for l in open(os.path.expanduser("~/leads.jsonl"), encoding="utf-8")]
print(collections.Counter(r["recommended"] for r in rows).most_common())
print("заявок:", len(rows), "| с username:", sum(1 for r in rows if r["username"]))
EOF
```

Пишите каждому, кто прошёл квиз, в тот же день: «Вижу, вам подошёл [аромат] — а что обычно носите?». Квиз даёт повод для разговора, разговор даёт продажу.

## 8. Чего бот не делает

- **Не рассылает незнакомым.** Только тем, кто сам нажал `/start`. Рассылки по спарсенным базам — бан аккаунта и нарушение правил Telegram.
- **Не приводит подписчиков.** Он превращает интерес в диалог; людей по-прежнему надо приводить (см. `../rost-bez-byudzheta.md`).
- **Не заменяет человека.** Снимает повторяющиеся вопросы, собирает лиды, отдаёт сложное владельцу.
- **Не хранит данные в облаке.** `leads.jsonl` — файл на телефоне, это персональные данные: в публичный репозиторий их не кладём (`.gitignore` уже закрывает `leads.jsonl` и `demo_leads.jsonl`).
- **Не работает без интернета.** Если телефон мешает — код без изменений переносится на любой сервер с Python.
