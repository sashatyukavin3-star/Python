# Запуск бота на телефоне (Termux) — 5 минут

## Почему была ошибка

```
bash: cd: /data/data/com.termux/files/home/bot: No such file or directory
bash: ./run_bot.sh: No such file or directory
```

Это значит одно: **папки с ботом на телефоне ещё нет** — `cd` в несуществующую папку не сработал, и `./run_bot.sh` тоже не нашёлся. Файлы бота лежат в GitHub, их нужно один раз скачать (шаг 2).

Проверить, где вы и что рядом:

```bash
pwd
ls
```

---

## Шаг 1. Поставить Python (и git)

```bash
pkg update
pkg install -y python git
```

Проверка: `python --version` печатает 3.10 или новее.

## Шаг 2. Скачать бота — любым из двух способов

**Способ А, через git (рекомендую, потом легко обновлять):**

```bash
cd ~
git clone -b arena/6711df4c-python https://github.com/sashatyukavin3-star/Python.git perfume
cd ~/perfume/parfum-ai-kit/bot
```

**Способ Б, без git (если git не ставится):**

```bash
cd ~
curl -L -o bot.tar.gz https://codeload.github.com/sashatyukavin3-star/Python/tar.gz/refs/heads/arena/6711df4c-python
tar xzf bot.tar.gz
cd ~/Python-arena-6711df4c-python/parfum-ai-kit/bot
```

**Проверка, что вы на месте:**

```bash
ls
```

В списке должны быть `run_bot.sh`, `quiz_bot.py`, `config.json`, `engine.py`.

## Шаг 3. Вписать токен и id

Скопируйте блок из чата целиком (там уже ваши значения) — или заполните шаблон:

```bash
cat > .env <<'EOF'
TELEGRAM_TOKEN=<токен из @BotFather>
OWNER_CHAT_ID=<ваш id от @userinfobot>
LEADS_FILE=$HOME/leads.jsonl
EOF
chmod 600 .env
```

Проверить, что записалось (секрет не покажется целиком):

```bash
grep -c TELEGRAM_TOKEN .env    # должно быть 1
```

## Шаг 4. Первый запуск

```bash
chmod +x run_bot.sh
./run_bot.sh
```

Что должно появиться:

```
Проверка настроек…
✔ Токен по форме похож на настоящий: 9185776438:••••••••
✔ Токен рабочий: бот @ваш_бот
✔ Конфиг читается: 5 вопросов, 5 ароматов, бренд «PARFUM»
✔ Владельцу можно писать: id 8206258615
✔ Файл заявок доступен для записи: /data/data/com.termux/files/home/leads.jsonl

Всё в порядке. Запускайте: python3 quiz_bot.py

Бот «PARFUM» запущен: 5 вопросов, 5 ароматов.
Заявки пишутся в /data/data/com.termux/files/home/leads.jsonl. Ctrl+C — остановить.
```

**Если `.env` ещё не создан**, `run_bot.sh` сам сделает его из шаблона и попросит вписать токен: `nano .env` → вставить → `Ctrl+O`, `Enter`, `Ctrl+X` → снова `./run_bot.sh`.

## Шаг 5. Проверка в Telegram

1. Откройте бота, нажмите **/start**.
2. Пройдите квиз как клиент (5 кнопок).
3. Вам в личку придёт «Новый подбор аромата» — значит уведомления работают.
4. Проверьте `/price` и `/delivery`.

**Важно:** пока вы не нажали `/start`, Telegram запрещает боту писать вам первым — уведомления не придут, и `selfcheck` честно скажет «Не удалось написать владельцу».

## Чтобы работал в фоне

```bash
pkg install -y tmux
tmux new -s bot
./run_bot.sh
# выйти, не выключая бота: Ctrl+B, затем D
```

Вернуться к боту: `tmux attach -t bot`.
Android: «Настройки → Приложения → Termux → Батарея → Без ограничений».
После перезагрузки телефона бота нужно запустить заново.

## Обновить до свежей версии

```bash
cd ~/perfume
git pull
./parfum-ai-kit/bot/run_bot.sh
```

## Если что-то не так

| Сообщение | Что означает | Что делать |
|---|---|---|
| `No such file or directory` | вы не в папке бота | `pwd`, `ls`; вернитесь в шаг 2 |
| `Permission denied` | у файла нет права запуска | `chmod +x run_bot.sh` |
| `Нет TELEGRAM_TOKEN` | `.env` пустой или не там | шаг 3, файл должен лежать рядом с `run_bot.sh` |
| `Unauthorized` | токен неверный или отозван | @BotFather → /revoke → новый токен в `.env` |
| `chat not found` | бот не может писать первым | откройте бота, `/start` |
| `нет связи с api.telegram.org` | сеть/VPN блокирует Telegram | выключите VPN, проверьте интернет |
| Квиз работает, заявки не приходят | `OWNER_CHAT_ID` чужой | свой id у @userinfobot |
| Бот «молчит» через час | Android усыпил Termux | `termux-wake-lock`, tmux, «Батарея без ограничений» |

## Остановить бота

`Ctrl+C` в его окне, либо `tmux kill-session -t bot`.

## Потрогать бота без Telegram

```bash
python3 demo_server.py
```

Затем открыть в браузере телефона `http://localhost:8000` — тот же квиз, только в браузере, токен не нужен.
